📖 Overview

Stress is a leading cause of anxiety, depression, road rage, and reduced productivity.
This project aims to predict stress levels using a trained ML model and provide real-time actionable suggestions through a user-friendly desktop app.

The application is designed for:-

🧑 Students

🚗 Daily commuters

👔 Working professionals

🧠 Psychologists / wellness coaches

🖥 Developers exploring ML + GUI projects

🎯 Key Features
🔹 Machine Learning Predictions

Stress Level (0–10)

Anxiety Level

Depression Level

Behavior in Traffic

Stress Impact Category (Less / Mild / Severe)

🔹 Tkinter GUI

Auto-filled dropdowns for categorical inputs

Number validation for numeric fields

Clean two-column layout

Custom background image

🔹 Intelligent Suggestions

Based on stress severity:

Breathing techniques

Mindfulness advice

Lifestyle tips

When to seek therapy

🔹 Failsafe Model Loading

Handles missing models gracefully

Provides debug logs

Prevents crashes due to invalid input
